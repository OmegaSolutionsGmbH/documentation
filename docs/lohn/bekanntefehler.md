# Fehlerbehebung

## Die App wird nicht angezeigt

Prüfen Sie:

- Ist die Erweiterung installiert?
- Verfügt der Benutzer über die erforderlichen Berechtigungssätze?
- Ist die verwendete Business-Central-Version unterstützt?
- Wurde die Umgebung nach der Installation neu geöffnet?

## Support kontaktieren

Halten Sie für eine Supportanfrage folgende Informationen bereit:

- Business-Central-Version
- Omega-App-Version
- genaue Fehlermeldung
- betroffene Seite oder Aktion
- Zeitpunkt des Fehlers
