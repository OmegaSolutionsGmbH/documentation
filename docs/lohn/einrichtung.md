# Einrichtung

## Grundlegende Einrichtung

Nach der Installation müssen die Grundeinstellungen des Moduls eingerichtet werden.

1. Öffnen Sie die **Omega Lohn Einrichtung**.
2. Prüfen Sie Nummernserien und Buchungseinstellungen.
3. Hinterlegen Sie die erforderlichen Berechtigungen.
4. Führen Sie den Einrichtungsassistenten vollständig aus.

## Abschlusskontrolle

- Alle Pflichtfelder sind ausgefüllt.
- Die benötigten Benutzer besitzen die passenden Berechtigungssätze.
- Testdaten lassen sich ohne Fehlermeldung verarbeiten.
