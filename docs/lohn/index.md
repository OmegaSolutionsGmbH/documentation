

# Lohn & Gehalt

Die zentrale Dokumentation für das Omega Modul **Lohn & Gehalt**.

## Erste Orientierung

| Bereich | Inhalt |
|---|---|
| Installation | Voraussetzungen und Installation der Erweiterung |
| Einrichtung | Grundeinstellungen und notwendige Stammdaten |
| Erste Schritte | Typischer Ablauf für neue Anwenderinnen und Anwender |
| Fehlerbehebung | Häufige Fragen und konkrete Lösungswege |

::: tip Empfehlung
Beginnen Sie mit der **Installation** und arbeiten Sie anschließend die **Einrichtung** vollständig durch.
:::
