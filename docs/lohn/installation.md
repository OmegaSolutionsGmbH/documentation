# Installation

## Voraussetzungen

- Unterstützte Version von Microsoft Dynamics 365 Business Central
- Berechtigung zum Installieren von Erweiterungen
- Gültige Omega Lizenz

## App installieren

1. Öffnen Sie in Business Central die Seite **Erweiterungsverwaltung**.
2. Wählen Sie **Erweiterung hochladen**.
3. Wählen Sie die bereitgestellte `.app`-Datei aus.
4. Bestätigen Sie die Installation.
5. Prüfen Sie nach Abschluss, ob die Erweiterung als installiert angezeigt wird.

::: warning Produktivsystem
Führen Sie Aktualisierungen nach Möglichkeit zuerst in einer Sandbox-Umgebung durch.
:::
