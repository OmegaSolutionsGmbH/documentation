# Unterstützte Berichte

Die folgende Tabelle enthält alle Berichte, für die eine ordnungsgemäße Funktion mit Omega PDF erwartet wird.

::: info Hinweis
Auch weitere, hier nicht aufgeführte Berichte können mit Omega PDF funktionieren. Diese wurden jedoch nicht ausdrücklich als unterstützt dokumentiert.
:::

## Bedeutung der Spalten

| Spalte | Beschreibung |
| --- | --- |
| **Berichts-ID** | Eindeutige ID des Berichts in Business Central. |
| **Steuerstring** | Gibt an, ob der Bericht mithilfe von Steuerstrings verarbeitet werden kann. |
| **RequestPage** | Gibt an, ob die Anforderungsseite des Berichts im vorgesehenen Verarbeitungsablauf unterstützt wird. |
| **Bemerkung** | Enthält zusätzliche Voraussetzungen oder Hinweise zur Verwendung des Berichts. |
