# Benutzereinrichtung

Unter den Benutzerberechtigungen können sie festlegen, welcher Benutzer dieses Modul verwenden 
darf, bzw. auch in welchem Umfang

Öffnen Sie über die Suche in Business Central die Seite:

```text
Benutzer Berechtigungen
```



---



Hier können pro Benutzer folgende Berechtigungen vergeben bzw. freischalten

| Name                       | Beschreibung                                                            |
| -------------------------- | ----------------------------------------------------------------------- |
| Verschlüsselung berechtigt | Erlaubt es dem Benutzer, Dokumente zu verschlüsseln                     |
| Download berechtigt        | Erlaubt es dem Benutzer, verarbeitete Dokumente gesammelt zu Downloaden |
