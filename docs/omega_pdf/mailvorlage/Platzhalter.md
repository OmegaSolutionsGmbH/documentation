
# Platzhalter

Auf der rechten Seite der Mailvorlage befindet sich der Bereich **„Platzhalter“**. Dort werden die verfügbaren Platzhalter in zwei Gruppen angezeigt:

- **Platzhalter Tabelle**
- **Platzhalter Bericht**

### Platzhalter Tabelle

Die **„Platzhalter Tabelle“** wird automatisch befüllt, sobald das Feld **„Personen“** in der Mailvorlage einen Wert enthält.

Diese Platzhalter enthalten Daten der ausgewählten Personengruppe, beispielsweise Name oder Personalnummer eines Dienstnehmers.

### Platzhalter Bericht

Damit **„Platzhalter Bericht“** zur Verfügung stehen, müssen folgende Voraussetzungen erfüllt sein:

1. Im Feld **„Exklusiv für den Bericht“** ist eine Berichts-ID hinterlegt.
2. Der ausgewählte Bericht wurde mindestens einmal mit Omega PDF verarbeitet.

Bei der ersten Verarbeitung extrahiert und speichert Omega PDF die erforderlichen Berichtsinformationen. Anschließend können die daraus erzeugten Platzhalter in der Mailvorlage verwendet werden.
